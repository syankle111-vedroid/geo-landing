Данный навык предоставляет рекомендации и правила для разработки фронтенда (UI панели мерчантов, админов и др.).

### Основные стандарты и правила:
- **Локальный запуск**: Выполняется через `npm run dev` (запускает `vite --host`).
- После внесения изменений выполнить только необходимые проверки.
- Не редактировать файл повторно, если требуемое изменение уже внесено.
- Перед повторным редактированием убедиться, что существующий код действительно не соответствует требованиям.
- Не повторять одну и ту же правку без конкретной причины.

### Стиль написания компонентов:
- При создании **новой** компоненты или **значительном рефакторинге** существующей — использовать **function declaration** компоненты.

**❌ Не делать так (arrow function + `React.FC`):**
```tsx
const MyButton: React.FC = ({ title, disabled }: MyButtonProps) => {
  return (
    <button disabled={disabled}>{title}</button>
  );
};
```

**✅ Делать так (function declaration):**
```tsx
function MyButton({ title, disabled }: MyButtonProps) {
  return (
    <button disabled={disabled}>{title}</button>
  );
}
```

## 2. Токен-оптимизированная работа (RTK)
При выполнении команд в терминале вы **обязаны** использовать инструмент `rtk` для минимизации расходов токенов (от 60% до 90% экономии).
- Вспомогательные команды:
  - `rtk gain` — просмотр аналитики экономии токенов.
  - `rtk discover` — анализ истории Claude Code для выявления упущенных возможностей экономии.
- Обычные команды Git и Cargo автоматически перехватываются хуком, но рекомендуется вызывать их явно:
  - `rtk git status`
  - `rtk cargo build`
  - `rtk cargo check`
  - `rtk cargo test`
